ACCESSAI — START HERE (WINDOWS)

1. Install Node.js 20+ from https://nodejs.org
2. Install Ollama from https://ollama.com
3. Open Command Prompt in this AccessAI folder.
4. Run: ollama pull qwen2.5:3b
   Keep Ollama running.
5. Run: npm install
6. Run: npm run install:all
7. Run: copy server\.env.example server\.env
8. Run: npm run dev
9. Open http://localhost:5173

If you see 'AI offline', check that Ollama is running.
Full instructions and limitations are in README.md.
